# Dio trilha-java-basico

## Desafio Controle de Fluxo

Este projeto em Java foi desenvolvido para praticar conceitos de controle de fluxo e exceções. Ele permite que o usuário insira dois parâmetros inteiros, e realiza uma contagem do primeiro ao segundo parâmetro, exibindo cada número no console. Se o segundo parâmetro for menor que o primeiro, uma exceção personalizada é lançada.

## Descrição

O projeto consiste em uma classe principal chamada `Contador`, que contém a lógica de contagem e validação dos parâmetros fornecidos. Se o segundo parâmetro for menor que o primeiro, uma exceção `ParametrosInvalidosException` é lançada, e uma mensagem de erro é exibida.

## Pré-requisitos

- Java 11 ou superior
- IDE como IntelliJ IDEA, Eclipse, ou outra de sua preferência.

## Como Usar

1. Clone o repositório do projeto:
```
  https://github.com/EdsonPsil/dio-trilha-java-basico.git
```   

2. Importe o projeto em sua IDE preferida.

3. Execute a classe `Contador` a partir da sua IDE.

4. No terminal, insira o primeiro e o segundo parâmetros quando solicitado. O programa exibirá a contagem do primeiro até o segundo número. Caso o segundo parâmetro seja menor que o primeiro, a seguinte mensagem de erro será exibida:

   ```
   O segundo parâmetro deve ser maior que o primeiro
   ```

## Estrutura do Projeto

- `src/main/java`: Contém a classe `Contador`, responsável por realizar a lógica de contagem.
- `src/main/java`: Contém a classe `ParametrosInvalidosException`, que lida com a exceção de negócio no sistema.
